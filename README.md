# Список сотрудников

Небольшой список сотрудников: регистрация, вход и добавление записей. Данные лежат в SQLite и не пропадают после перезапуска.

## Запуск

Нужен Node.js 22 или новее. Сервер использует встроенный `node:sqlite`.

В первом терминале:

```
cd backend
npm install
npm run dev
```

API поднимается на http://localhost:3001.

Во втором:

```
cd frontend
npm install
npm run dev
```

Интерфейс: http://localhost:5173. Запросы к `/api` проксируются на сервер.

Сначала зарегистрируйтесь. В базе уже есть 5 сотрудников. Поиск идёт по ФИО, отдел выбирается в фильтре. Нового сотрудника можно добавить формой слева — пустые поля сервер не примет.

Пароль хранится как bcrypt-хеш. Сессия — JWT в cookie на 7 дней. HttpOnly не даёт JavaScript прочитать cookie. SameSite=Lax ограничивает её отправку в межсайтовом запросе и снижает риск CSRF. Secure в production требует HTTPS. Без cookie методы сотрудников отвечают 401. В production без `JWT_SECRET` сервер не стартует. Локально `npm run dev` может идти без секрета: тогда берётся запасной ключ из кода.

База SQLite создаётся автоматически при первом запуске, в ней сразу 5 сотрудников.
